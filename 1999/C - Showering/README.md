Task $$$i$$$ is represented as an interval $$$(l_i$$$, $$$r_i)$$$, which means that Alex is busy and can not take a shower in that time interval (at any point in time strictly between $$$l_i$$$ and $$$r_i$$$). <span class="tex-font-style-bf">No two tasks overlap.</span></p><p>Given all $$$n$$$ time intervals, will Alex be able to shower that day?
